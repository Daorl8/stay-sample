# stay-sample

GOYO · 고요 — 강원 양양 독채 스테이 샘플 (이피웹 포트폴리오).

- **목적:** 포트폴리오 다양화 — `샘플_다양성_매트릭스.md`의 빈 셀 점유: **롱스크롤 서사-퍼스트 · 풀블리드 교차 레이아웃 · 스티키 상단 내비 · 다크 드라마틱 무드**. (기존 네일/필라/학원/플라워의 *웜뉴트럴+밝은 톤*에서 처음으로 **다크 팔레트**로 이탈 — 무드 축 점유.)
- **팔레트:** 차콜 `#14130F` 베이스 + 웜 오프화이트 `#EDE7DB` + 앰버골드 `#B89160` 액센트. (2~3색 절제 유지, 패밀리만 다크로)
- **스택:** 정적 HTML/CSS/JS (단일 `index.html`, 인라인). 빌드 없음.
- **호스팅:** Cloudflare Workers(무료·상업 허용). 배포 후 `/.git/config` 404 확인.
- **배포 주소(예정):** `stay-sample.lgt3232.workers.dev`
